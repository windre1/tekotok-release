# TEKOTOK Releases

Repositori ini hanya menyimpan berkas rilis (installer) untuk auto-update
aplikasi **TEKOTOK**. Kode sumber TEKOTOK tidak dipublikasikan di sini.

Unduh versi terbaru lewat tab **[Releases](https://github.com/windre1/tekotok-release/releases/latest)**.

TEKOTOK yang sudah terpasang bisa memperbarui dirinya sendiri: buka aplikasi,
lalu masuk ke tab **Update** di sidebar.
